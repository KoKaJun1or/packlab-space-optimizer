# PackLab 📦

A lightweight 2D space optimization tool built with **Godot Engine**. 

### Features
* **Multiple Shapes:** Support for triangles, squares, and hexagons.
* **Multi-Floor Packing:** Automatically calculates vertical floors based on package and workspace height.
* **Statistics & Visualization:** Real-time calculation of area, fill percentage, and a visual vertical breakdown window.
* **Open Source:** Built for easy tweaking and custom use cases.
